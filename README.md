# বেতন নির্ধারণী বিবরণী — জাতীয় বেতন স্কেল ২০২৬

জাতীয় বেতন স্কেল ২০২৬ (চাকরি (বেতন ও ভাতাদি) আদেশ ২০২৬, এস.আর.ও নং-৩৪৭-আইন/২০২৬, তারিখ ১৭ সেপ্টেম্বর ২০২৬) অনুযায়ী কর্মকর্তা/কর্মচারীর **বেতন নির্ধারণী বিবরণী** তৈরি ও এক পাতা A4-এ প্রিন্ট করার একটি ওয়েব অ্যাপ। সীতাকুণ্ড পৌরসভার প্যাডে সাজানো।

A single-page web app (plain HTML/CSS/JS, no build step, no server) that prepares and prints the Bangladesh National Pay Scale 2026 pay fixation statement on one A4 page.

## ব্যবহার

1. `index.html` ফাইলটি Chrome, Edge বা Firefox-এ খুলুন। ইন্টারনেট ছাড়াও চলে (ইন্টারনেট থাকলে Noto Serif Bengali ফন্ট লোড হয়)।
2. বাম পাশের ফর্মে তথ্য দিন — বেতন গ্রেড ও ক্রমিক ৭ (৩০ জুন ২০২৬ তারিখে গৃহীত মূল বেতন) দিলেই ক্রমিক ৮ থেকে ২৩ নিজে থেকে হিসাব হয়। দরকার হলে যেকোনো হিসাব "সম্পাদনা" চেপে হাতে বসানো যায়।
3. ডান পাশে A4 প্রিভিউ দেখে **প্রিন্ট করুন** চাপুন।

ফর্মের তথ্য ব্রাউজারেই (localStorage) জমা থাকে, কোথাও পাঠানো হয় না।

### অনেকজনের বিবরণী একসাথে

1. **Excel ছক ডাউনলোড** চেপে ফাঁকা ছক নিন (অথবা এই রিপোজিটরির `বেতন_নির্ধারণ_তথ্য_ছক.xlsx`)।
2. প্রতি সারিতে একজন কর্মকর্তা/কর্মচারীর তথ্য লিখুন।
3. **Excel থেকে আনুন** দিয়ে ফাইলটি দিন — তালিকা থেকে একজনকে বেছে প্রিন্ট করুন, অথবা **সবার বিবরণী প্রিন্ট** দিয়ে প্রত্যেকের বিবরণী আলাদা পাতায় প্রিন্ট করুন।

## হিসাবের নিয়ম

| ক্রমিক | হিসাব |
|---|---|
| ৮ | ২০১৫ স্কেলে গ্রেডের প্রারম্ভিক মূল বেতন |
| ৯ | ৭ − ৮ |
| ১০ | ২০২৬ স্কেলে গ্রেডের প্রারম্ভিক মূল বেতন |
| ১১ | ১০ + ৯ |
| ১২ | ২০২৬ স্কেলের সমধাপ, না থাকলে পরবর্তী উচ্চতর ধাপ [অনুচ্ছেদ ৫(খ)] |
| ১৩ | ১২-এর পরবর্তী ধাপ (একটি ইনক্রিমেন্ট) [অনুচ্ছেদ ৯(২)] |
| ১৪ | = ৭ |
| ১৫ | ১২ − ১৪ |
| ১৬ | ১৫ × ৪০% (১ম–৯ম গ্রেড) / ৫০% (১০ম–২০তম গ্রেড) |
| ১৭ | ১৪ + ১৬ |
| ১৮ | ১৭ + (১৩ − ১২) — ০১/০৭/২০২৬ থেকে কার্যকর |
| ১৯, ২১ | ১৫ × ৩০% (১ম–৯ম গ্রেড) / ২৫% (১০ম–২০তম গ্রেড) |
| ২০ | ১৮ + ১৯ — ০১/০১/২০২৭ থেকে কার্যকর |
| ২২ | ২০ + ২১ — ০১/০৭/২০২৭ থেকে ১০০% |
| ২৩ | ২২-এর পরবর্তী ধাপ (বার্ষিক বেতন বৃদ্ধিসহ) |

বেতন স্কেলের ধাপগুলো গেজেটের অনুচ্ছেদ ৩(১)-এর সারণি থেকে নেওয়া। চূড়ান্ত করার আগে হিসাব শাখায় যাচাই করে নিন।

## প্রিন্ট সেটিং

প্রিন্টের ঘরে: **Paper size: A4**, **Margins: Default**, **Scale: Default/১০০%**, এবং হলুদ হাইলাইট প্রিন্টে আনতে **Background graphics** চালু রাখুন।

## ফাইল

- `index.html` — পুরো অ্যাপ (লোগো ও ফাঁকা Excel ছক ফাইলের ভেতরেই রাখা)
- `বেতন_নির্ধারণ_তথ্য_ছক.xlsx` — অনেকজনের তথ্য পূরণের ফাঁকা Excel ছক
